FORM/0 BUILD SPEC — quick reference (digest of docs/SPEC.md; the .md is authoritative)

WHAT: anonymous, wordless 3D imageboard. Browser-only, talks directly to Nostr
relays + Blossom. One canvas, Babylon.js. Posts = animated GLB models w/ own
cameras + optional embedded audio.
GOALS: (1) real content from real relays on first run, no config;
(2) bun run build:standalone -> ONE .html from file://, fetches only user content.

STACK: TypeScript strict + Vite + Babylon(core/gui/loaders/serializers) +
nostr-tools, Bun as toolchain, Vitest+Playwright for tests. No React/Vue/Three/CDN.

BUILD ORDER (gated): skeleton -> relay pool (>=20 live GLBs) -> Blossom+SHA
(>=10) -> local posters 512x320 -> board -> RTT preview pool -> viewer/thread/
network -> studio publish -> paint editor -> standalone.

MEASURED NETWORK: '#m' filter = 66/66 models (bare kinds = 94% junk); no
poster tags exist in the wild -> render posters locally; form-zero content
exists (24 posts, 12 replies/7 roots); Draco mandatory, local decoders, zero CDN.

TRAPS: 13 in the spec (SVG->PNG, emissive white-out, calc() ADT, RTT->meshes,
rejection memory, scene audio emitter, side-effect imports, BOOT/BOARD '#/',
ARIA clobber, trusted-click dialogs, RTT interleave, no dist/ commits).

AMENDMENTS (override earlier wording): 1 HTML HUD ok for chrome. 2 replies +
badges in Babylon. 3 thread = 2D force-relaxed tree map. 4 scroll inertia
setting. 5 settings own background (engine must not reset clearColor).
6 posters ALWAYS auto-fit (authored cameras only in viewer). 7 offscreen
renders via scene.render() not rtt.render(). 8 no IBL (lights-only). 9 serialize
poster renders (mutex), concurrent downloads <=3. 10 paint editor's primary job
= hand-writing text (ink-style). 11 editor priorities: handwriting -> animation
editing -> audio recording (getUserMedia+MediaRecorder). 12 phone-pose camera
while recording (DeviceOrientation rotation; WebXR for translation; never
double-integrate DeviceMotion acceleration). 13-36 (added by other agents):
flat-camera contract, alpha-blend option, offscreen clears, aspect-aware
frameDistance, dominantFacing thin-axis, multi-touch via native events, inline
SVG HUD, one-model view tokens, spinner loading, demand-driven render loop,
virtualised board, viewport-gated work, cheap posters, curated glTF loader,
persistent shaders, async PBO readPixels, worker offload, decode-once bytes,
no-mipmap DynamicTextures, honest settings schema (~50 settings, 11 groups),
on-demand pipelines, conditional image processing, non-destructive texture cap.
41 VR support: WebXR immersive viewing in the viewer (6-DOF head tracking,
same canvas/engine, enter-VR action hidden when unsupported); HTTPS + capable
browser, graceful degrade, reduced-motion respected. 42 MANY settings: a large,
growing settings surface (see src/settings/schema.ts, ~50 settings) — new
tunables (thread mode, VR toggle, cameras, endpoints) are schema entries,
never hard-coded. 43 thread view = 3 modes: (a) 2D posters (current),
(b) tree view, (c) 3D = actual GLB models instead of textures; in 3D each node
shows its real model through the model's MAIN camera applied as the MODEL
transform vs a static camera (model rotated by inverse of main-cam rotation, at
the node's camera position; thread camera is only a position) — when centered,
thread view == model's main-camera view. Fall back to auto-fit when no camera.
50-53 preview width slider, viewer live-preview hand-off, zoom-scaled
thread RTTs, hotkey typing guard. 54 PAINT EDITOR: packed store + thin
instances + DDA + native coalesced pointer events; bake before
GLTF2Export; undo = inverse commands (cap 100). Guard: paint-unit.mjs.
44-47 SECURITY: owned-post deletion secrets are AES-256-GCM envelopes under a
non-extractable IndexedDB key (event-id AAD; plaintext migration); persisted
settings/network shapes are schema/type/range validated; sidecar imports are
local-only and preflighted (128 files/20 MiB, GLB validate-before-load,
glTF/OBJ complexity caps); embedded and data-URI image dimensions/MIME/decoded
memory are checked before decode, with SVG/unknown formats failing closed.
