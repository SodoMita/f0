CONVENTIONS — quick reference (digest of docs/CONVENTIONS.md)

TERMINOLOGY: it's a PAINT editor (Paint 3D-style), never a "voxel editor".
Free overlapping shape strokes; the fine grid is snapping-only.

TOOLCHAIN: Bun (bun.lock), not npm. TS strict, no `any` in exports. Vite (two
configs: normal + standalone). No React/Vue/Three/CSS-framework/CDN.

CODE: no file over ~400 lines, one job per module. Comment WHY, not what; name
every engine-bug workaround. Babylon deep imports only. ThreadMeta types live
in protocol/thread-index.ts.

RENDERING: card imagery on real meshes (ortho, 1 unit = 1 px), not GUI. Custom
unlit shader for 2D quads (StandardMaterial unreliable). Transparent previews:
RTTs clear alpha 0, shader passes alpha.

VERIFY BEFORE DONE: bun run build -> bun scripts/smoke.mjs -> features.mjs ->
capture.mjs + python3 scripts/visual_critique.py. Visual claims need screenshots
+ critique output (agents have no vision). Zero-CDN assert. Live tests must
degrade gracefully on flaky relays.

GIT: main branch, rebase before push, atomic commits, never commit
node_modules/release/standalone/shots/secrets. Deploy is automatic on push.

FOUND A BUG: fix it, then record twice — SPEC.md AMENDMENTS + STATUS.md debt.
