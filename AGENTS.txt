AGENTS — how to work on this repo (digest of AGENTS.md)

FORM/0 = anonymous wordless 3D imageboard. Browser-only, Nostr relays +
Blossom, one canvas, Babylon.js. Posts = animated GLB models.
Goals: real content on first run; bun run build:standalone -> ONE .html.

FIRST STEPS: bun install · bun run dev · bun run build · bun run build:standalone.

REQUIRED READING: docs/SPEC.md (authoritative, incl. AMENDMENTS) ·
ARCHITECTURE.md · STATUS.md (claim a task) · CONVENTIONS.md ·
RESEARCH-EDITORS.md (before Studio/editor work).

NON-NEGOTIABLE (each cost real debugging):
 1 deep imports only (never the @babylonjs/core barrel)
 2 one engine/context; engine must not reset scene.clearColor on swap
 3 validate GLBs before Babylon loads (model/limits.ts) — crash guard
 4 offscreen renders via scene.render(), never rtt.render()+renderList
 5 no scene.environmentTexture (IBL blackened PBR) — lights-only
 6 posters ALWAYS auto-fit; authored cameras only in the viewer
 7 display double-sided; never modify source GLB
 8 side-effect imports: Culling/ray (pick), screenshotTools, loaders glTF
 9 per-path texture flip matrix (posters flip Y; RTT + badges don't)
10 zero CDN (local Draco, blank KTX2/MSC URLs)
11 never commit node_modules/release/standalone/shots/tsbuildinfo

VERIFY (agents have no vision; pixel checks are the eyes):
 bun run build && smoke.mjs && features.mjs && capture.mjs + visual_critique.py

MULTI-AGENT: one agent per area, claim in STATUS, rebase before push, atomic
commits, fix-forward (record bugs in SPEC AMENDMENTS + STATUS). Deploy is
automatic via GitHub Actions; don't hand-edit the published artifact.
